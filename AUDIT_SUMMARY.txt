END-TO-END FLOW VERIFIED WORKING:
  1. Student logs in (email/OTP) → gets JWT token
  2. Starts check-in → system selects next due topic via SM-2 scheduling
  3. Types explanation → Claude Haiku evaluates, returns mastery_score & gap_type
  4. Receives AI feedback → "Continue to Practice" button shown
  5. Practices widget (selected based on gap_type) → submits answer
  6. Re-explains concept → Claude Sonnet re-evaluates with reasoning
  7. Mastery score updated → SM-2 metrics recalculated, nextDueAt changed
  8. XP awarded → streaks updated, badges checked
  9. Progress dashboard shows updated stats → parent view reflects changes
